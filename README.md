# 자취 라이프 대시보드

자취 생활을 관리하는 개인용 웹앱 (이사 준비 · 가계부 · 식단 · 운동 · 통합 홈).
설치할 라이브러리 없이 HTML/CSS/JavaScript만으로 만들었고, 기능은 "모듈" 단위로 하나씩 붙여 나간다.
처음 열면 입주일과 닉네임(선택)을 묻고, 이 값은 코드가 아니라 각자의 브라우저에만 저장된다.

## 수정하고 다시 올리기 (배포 후)

코드를 고친 뒤 이 폴더에서 아래 세 줄을 실행하면 1~2분 뒤 사이트에 반영된다.

```bash
git add .
git commit -m "무엇을 바꿨는지"
git push
```

폰에서 바로 안 바뀌어 보이면 앱을 완전히 닫았다가 다시 열기 (서비스 워커가 새 파일을 받아옴).

## 실행하는 법

**가장 간단하게:** `index.html`을 더블클릭해서 브라우저로 열기. (데이터 저장까지 다 됨)

**폰 홈 화면에 앱처럼 추가하려면(PWA)** 웹 서버로 열어야 한다.
- 컴퓨터에서 테스트: 이 폴더에서 아래 명령을 실행하고 브라우저로 `http://localhost:5173` 접속
  ```bash
  python -m http.server 5173
  ```
- 폰에서 쓰기: GitHub Pages 같은 무료 호스팅에 이 폴더를 올린 뒤, 폰 크롬/삼성 인터넷에서 열고 메뉴 → "홈 화면에 추가"

> ⚠️ 데이터는 **그 브라우저 안에만** 저장된다. 폰과 컴퓨터는 서로 데이터가 다르니,
> 옮길 때는 설정 → 내보내기(JSON 파일) → 다른 기기에서 가져오기를 쓴다.
> 브라우저 기록/사이트 데이터를 지우기 전에도 꼭 내보내기!

## 폴더 구조

```

js/utils.js           날짜 계산, D-day, 금액 표시 등 공용 도우미 (U.xxx)
js/storage.js         저장 계층 (Store.get / Store.set / 백업)
js/app.js             앱 본체: 모듈 등록, 화면 전환, 설정, 토스트·모달
modules/home.js       통합 홈: 요약 타일, 오늘 할 일, 급한 D-day (각 모듈 api를 모아서 표시)
modules/moving.js     이사 준비 체크리스트

modules/workout.js    운동 기록 (세트 기록 · 주간 볼륨 · 종목별 성장 그래프)
modules/settings.js   입주일 변경, 백업 내보내기/가져오기, 초기화

sw.js                 서비스 워커 (오프라인에서도 열리게 파일 캐시)
icons/                앱 아이콘 (tools/make_icons.py로 PNG 생성)
```

## 동작 원리 (3가지만 알면 됨)

### 1. 모듈 = `App.register({...})` 한 번
각 기능 파일은 이런 객체 하나를 등록한다.

```js
App.register({
  id: 'budget',          // 주소가 #/budget 이 됨
  title: '가계부',
  icon: '💰',
  render(el) { el.innerHTML = '...'; },   // 이 화면을 그리는 함수
  widget(el) { ... },                      // (선택) 홈 아래쪽에 보여줄 자세한 카드
  api: {                                   // (선택) 홈·다른 모듈에 내주는 정보
    stat() { ... },                        //   홈 위쪽 요약 타일 하나
    deadlines() { ... },                   //   기한 있는 할 일 목록
  },
});
```

### 2. 화면 전환 = 주소의 `#/아이디`
메뉴를 누르면 주소가 `#/moving`처럼 바뀌고, `app.js`가 그 id의 모듈을 찾아 `render`를 호출한다.

### 3. 저장 = `Store`만 사용
모듈은 `localStorage`를 직접 쓰지 않고 `Store.get('키', 기본값)`, `Store.set('키', 값)`만 쓴다.
키는 `모듈id.이름` 형식으로 (예: `moving.items`).
나중에 기기 간 동기화가 필요해지면 `storage.js`의 `LocalBackend`만 서버용으로 바꾸면 된다.

### 4. 모듈끼리 정보 주고받기 = `api` + `App.use()`
다른 모듈의 저장 키를 직접 읽지 않고, 그 모듈이 `api`로 열어 둔 함수만 쓴다.

```js
// workout.js 에서 공개
App.register({ id: 'workout', ..., api: { hasWorkout, logsOn, weekSummary } });

// meal.js 에서 사용 (운동 모듈이 없어도 ?. 덕분에 에러 없이 넘어감)
const worked = App.use('workout')?.hasWorkout('2027-03-02');
```

지금 연결된 것: 식단 → "운동한 날" 표시 / 운동 → 그날 단백질 계획 표시.

## 새 모듈 추가하는 순서

1. `modules/새모듈.js` 파일 만들기 (`moving.js`를 복사해서 시작하면 편함)
2. `index.html`의 모듈 목록에 `<script src="modules/새모듈.js"></script>` 한 줄 추가
   (나열한 순서가 메뉴 순서. 설정은 맨 마지막에 두기)
3. `sw.js`의 `ASSETS` 목록에 파일 경로 추가
4. 홈에 나오게 하고 싶으면 아래 중 필요한 것만 만들기 → 홈에 자동으로 합쳐짐
   - `api.stat()` → 요약 타일
   - `api.deadlines()` → 오늘 할 일 / D-day
   - `widget(el)` → 아래쪽 자세한 카드

## 통합 홈 화면

위에서부터:

1. **인사 + 입주 D-day** (입주 후에는 "자취 N일째")
2. **요약 타일** — 각 모듈의 `api.stat()`을 모은 것: 이사 준비 진행률 / 이번 달 지출 / 오늘 단백질 / 이번 주 운동
3. **오늘 할 일** — 모든 모듈의 `api.deadlines()` 중 *기한 지남·오늘*인 것 + 홈에서 직접 적는 메모
   - 이사 준비 항목은 바로 체크 (되돌리기 가능)
   - 공과금은 `납부` 버튼 → 가계부 납부 창이 홈에서 바로 뜸
   - 유통기한 임박 재료는 `다 씀` 버튼
   - 직접 적은 할 일은 못 끝내면 다음 날에도 남아 있고("N일 전부터"), 끝낸 지 7일 지나면 자동 정리
4. **가장 급한 D-day** — 내일 이후 60일 안의 기한 중 가장 가까운 것 크게 + 다음 5개
5. **오늘 식단 / 오늘 운동** 카드 — 각 모듈의 `widget(el)`

`deadlines()`가 돌려주는 항목 모양:

```js
{
  key: 'bill:abc:2026-12',   // 겹치지 않는 이름
  icon: '🏠', title: '월세 납부',
  date: new Date(2027, 2, 2),
  source: '350,000원',        // 제목 아래 작은 글씨
  href: '#/budget',           // 눌렀을 때 갈 화면
  checkable: true,            // 체크박스로 보일지 (아니면 actionLabel 버튼)
  actionLabel: '납부',
  complete(onDone) { ...; onDone(); },   // 체크/버튼을 눌렀을 때 할 일
}
```

## 이사 준비 체크리스트 메모

- 기한은 날짜가 아니라 **"입주일 기준 며칠"**(`offset`)로 저장 → 설정에서 입주일을 바꾸면 전부 같이 움직임
- 특정 날짜가 정해진 일(예: 가스 개통 예약일)은 "날짜 직접 선택"으로 지정
- 기한 색: 빨강 = 지남, 주황 = 7일 이내
- 처음 열 때 기본 항목 35개가 채워짐 (월세 계약은 완료 상태). 필요 없는 건 눌러서 삭제

## 가계부 메모

- 탭 3개: **내역**(월 예산 대비 지출, 날짜별 기록) / **통계**(카테고리별 막대, 최근 6개월 추이) / **납부일**(고정 지출)
- 카테고리는 `budget.js` 맨 위 `CATS` 목록. `fixed: true`면 고정비로 집계됨. 새 카테고리는 여기에 한 줄 추가
- 고정 지출(월세·관리비·공과금·구독)은 "매달 N일" 또는 "매년 M월 N일"로 저장하고, 시작 월 이전에는 표시하지 않음
  (월세·관리비·공과금은 입주한 달부터 시작하도록 기본값이 들어가 있음. 금액은 0이라 직접 수정 필요)
- 납부일에서 체크 → 금액 확인 창 → **지출 내역에 자동 기록**. 그 기록을 지우면 납부 표시도 풀림
- 저장 키: `budget.tx`(지출), `budget.bills`(고정 지출), `budget.settings`(월 예산)

## 식단 메모

- 탭 4개: **식단**(요일 고르고 끼니별 메뉴 추가) / **장보기** / **냉장고** / **메뉴**(자주 먹는 메뉴 + 영양값 + 재료)
- 메뉴에 재료를 적어 두면, 그 주 식단에 들어간 재료 중 **냉장고에 없는 것만** 장보기 목록에 자동으로 모임
  (재료 이름은 띄어쓰기 무시하고 비교: "닭 가슴살" = "닭가슴살")
- 장보기에서 체크 → "냉장고에 넣기" 버튼으로 한 번에 냉장고로 이동
- 단백질 목표 = 체중 × 체중 1kg당 단백질(기본 1.6g). 식단 탭 "목표 ✎"에서 변경
- 기본 메뉴의 영양값은 대략치라 자기가 자주 먹는 것 위주로 고쳐 쓰기
- 저장 키: `meal.menus`, `meal.plan`, `meal.fridge`, `meal.shopping`, `meal.shopChecked`, `meal.settings`

## 운동 메모

- 탭 3개: **기록**(요일별 종목·세트) / **통계**(최근 8주 볼륨, 종목별 추정 1RM 그래프) / **종목**
- 새로 기록할 때 종목을 고르면 **지난번 세트가 자동으로 채워짐** → 무게·횟수만 고치면 됨
- 볼륨 = 무게×횟수 합. 맨몸 운동(무게 0)은 횟수만 기록
- 추정 1RM = 무게 × (1 + 횟수/30) (Epley 공식)
- 저장 키: `workout.exercises`, `workout.logs`
